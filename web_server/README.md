# Web Server Project - Intranet Setup

This project contains a series of Bash scripts and HTML files to configure a web server on Ubuntu 16.04. The project covers:

- Installing and configuring **Nginx**  
- Creating a main web page  
- Setting up **301 redirection**  
- Configuring a **custom 404 page**  
- Optional: Designing a **beautiful 404 page**  

All tasks are automated using Bash scripts without manual intervention.
